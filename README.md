## Exemple d'utilisation de la Todo List

Voici un exemple simple de structure HTML pour une Todo List :

```html
<div class="todo-container">
  <h1>Todo List</h1>
  <input type="text" id="task-input" placeholder="Ajouter une tâche...">
  <button id="add-btn">Ajouter</button>
  <ul id="task-list">
    <li>Tâche 1 <button class="delete-btn">Supprimer</button></li>
    <li>Tâche 2 <button class="delete-btn">Supprimer</button></li>
  </ul>
</div>
